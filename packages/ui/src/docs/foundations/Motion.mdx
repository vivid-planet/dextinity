# Motion

Motion explains where you are. Page transitions depend on their kind, with shared elements.

## Tokens

One curve for everything, three durations.

<LayerTokenTable source={motionSource} />

## Reduced motion

With the operating system's "reduce motion" setting, `--dextinity-motion-distance` becomes `0px` and the medium and long durations shrink to the short one, so everything that moves only crossfades. Components that move build their offsets on the distance token and get this for free. Try it in the demo below with "Reduce motion".
