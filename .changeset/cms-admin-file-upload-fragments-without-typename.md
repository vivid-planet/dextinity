Remove `__typename` from `GQLFinalFormFileUploadFragment` and `GQLFinalFormFileUploadDownloadableFragment`

The types are generated by GraphQL Code Generator, which only adds `__typename` to an operation type when the operation selects it.
Neither fragment selects `__typename`, so the optional `__typename?: "FileUpload"` field is gone.

If your project reads `__typename` from one of these types, select it in your own query and use that query's type instead.
