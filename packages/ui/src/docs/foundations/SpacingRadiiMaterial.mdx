# Spacing, radii & material

Spacing grid, corner radii, shadows, glass, and density. The values follow the brand, the color scheme, and the density picked in the toolbar.

## Spacing

A grid in steps of 4 px, plus 18 px for the space between glass panels.

## Density

A user setting, set with the `density` prop of `Theme`. Each density has fixed sizes; text keeps its size. On touch screens, compact stays at the sizes of standard. The column of the density picked in the toolbar is highlighted.
