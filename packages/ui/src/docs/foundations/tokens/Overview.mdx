# Tokens

The components take their colors, space, corner radii, fonts, and icons from CSS variables whose names start with `--dextinity-`. You can use these variables in your own styles, and change them in your own stylesheet.

Wrap your application in [`Theme`](?path=/docs/foundations-tokens-theme--docs). Outside it, the components have no styles, and the color variables have no value.

The tokens come in layers. Each layer only refers to the layers below it, so a new brand needs only its brand tokens:

1. **Primitives**: color scales, units, radii, border widths, font weights, and motion, with fixed values. Use the color scales only through the brand and semantic tokens.
2. **Brand**: the color scales, corner radii, and fonts of a brand, `--dextinity-brand-*`. See [Brands](#brands).
3. **Semantic**: colors of backgrounds, text, borders, actions, and feedback for each color scheme, and the sizes of text and space, which grow from the desktop breakpoint on.
4. **Components**: the tokens of each component, such as `--dextinity-button-*`. They use semantic and brand tokens, and the units, radii, and border widths of the primitives. Each component page lists them under "CSS variables".

- To give the components your colors, corner radii, and font, see [Customize brand](?path=/docs/foundations-tokens-customize-brand--docs).
- To replace or add icons, see [Customize icons](?path=/docs/foundations-icons-customize-icons--docs).
- To look up an icon, see [All icons](?path=/docs/foundations-icons-all-icons--docs).

## Use tokens in your styles

Use the tokens with `var()` in your own styles:

- **Colors** of backgrounds, text, and borders. They change with the color scheme.
    - `--dextinity-color-background-*`, `--dextinity-color-foreground-*`, `--dextinity-color-border-*`
    - For actions and feedback, such as errors: `--dextinity-color-action-*`, `--dextinity-color-feedback-*`
- **Space** between and around sections.
    - `--dextinity-space-layout-xs` to `--dextinity-space-layout-2xl`
- **Space** in small groups, such as chips.
    - `--dextinity-unit-*`
- **Corner radius** of surfaces, such as cards.
    - `--dextinity-brand-radius-surface`, `--dextinity-brand-radius-card`

Arrange the components with flexbox or grid, and set the space between them with `gap`:

```css
.panel {
    display: flex;
    flex-direction: column;
    gap: var(--dextinity-space-layout-xs);
    padding: var(--dextinity-space-layout-md);
    border: 1px solid var(--dextinity-color-border-default);
    border-radius: var(--dextinity-brand-radius-card);
    background-color: var(--dextinity-color-background-subtle);
    color: var(--dextinity-color-foreground-default);
}
```

## Color schemes

Set the color scheme with the `colorScheme` prop of `Theme`: `"light"`, `"dark"`, or `"high-contrast"`. To use another color scheme in a part of the application, wrap that part in another `Theme` with its own `colorScheme`.

## Brands

There are two brands, each in its own file under `src/theme/brands/`:

- **Dextinity** (`brand="dextinity"`, the default): for general applications. Indigo as the primary color, grey neutrals, and Inter.
- **AI Hub** (`brand="ai-hub"`): like Dextinity, with the violet of the AI Hub logo as the primary color. Fonts, corner radii, and neutrals stay the same, so that both look like one family.

Set the brand with the `brand` prop of `Theme`. A nested `Theme` without `brand` keeps the brand of the `Theme` around it. To give the components your own colors, see [Customize brand](?path=/docs/foundations-tokens-customize-brand--docs).
