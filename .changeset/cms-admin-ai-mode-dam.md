Let the AI Mode work with the DAM

On the DAM page, the agent of the AI Mode reads what the grid shows, searches and pages it, opens folders, and opens the form of a file, whose name, title, alternative text, and license it fills in as unsaved changes. The dialog that chooses a file offers none of this, so that the agent doesn't navigate in it.
