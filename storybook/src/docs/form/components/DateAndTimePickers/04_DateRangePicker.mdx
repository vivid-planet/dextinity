# Date-Range Picker

**`DateRangePicker` and `FinalFormDateRangePicker` from `@dextinity/admin-date-time` are deprecated. Use [`DateRangePicker`](?path=/docs/@dextinity/admin_components-datetime-daterangepicker--docs) or [`DateRangePickerField`](?path=/docs/@dextinity/admin_components-datetime-daterangepickerfield--docs) from `@dextinity/admin` instead.**

## Value type

The `value` prop and the value returned by `onChange` are objects with `start` and `end` values, each as a string in the format `YYYY-MM-DD`.

```ts
type DateRange = {
    start: string;
    end: string;
};
```
