# Date Picker

**`DatePicker` and `FinalFormDatePicker` from `@dextinity/admin-date-time` are deprecated. Use [`DatePicker`](?path=/docs/@dextinity/admin_components-datetime-datepicker--docs) or [`DatePickerField`](?path=/docs/@dextinity/admin_components-datetime-datepickerfield--docs) from `@dextinity/admin` instead.**

## Value type

The `value` prop and the value returned by `onChange` are a string in the format `YYYY-MM-DD`.
