# @dextinity/mail-react

`@dextinity/mail-react` is Dextinity's library for building responsive, themed HTML emails with React and MJML.

This Storybook is for developing and previewing components in isolation. For the full guide — installation, the theme system, MJML layout rules, and integrating with the Mail Templates Module — see the [Building HTML Emails](https://cms-docs.dextinity.com/docs/features-modules/building-html-emails/) documentation.
