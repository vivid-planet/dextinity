# Customize brand

The brand tokens set the color scales, the corner radii, and the fonts of all components. `@dextinity/ui` has two brands, Dextinity and AI Hub, which you select with the `brand` prop of `Theme` (see [Brands](?path=/docs/foundations-tokens-overview--docs#brands)). To give the components your own brand, override the brand tokens.

1. Create a global stylesheet. Put its rules outside any cascade layer.
2. In a `:root` rule, set the brand tokens that you want to change. Set all steps of a color scale.
3. Import the stylesheet once in your application.
4. Check the components in all color schemes.

This stylesheet makes teal the primary color, and decreases the corner radius of controls, such as buttons:

```css
:root {
    --dextinity-brand-radius-control: var(--dextinity-radius-md);

    --dextinity-brand-color-primary-50: var(--dextinity-color-teal-50);
    --dextinity-brand-color-primary-100: var(--dextinity-color-teal-100);
    --dextinity-brand-color-primary-200: var(--dextinity-color-teal-200);
    --dextinity-brand-color-primary-300: var(--dextinity-color-teal-300);
    --dextinity-brand-color-primary-400: var(--dextinity-color-teal-400);
    --dextinity-brand-color-primary-500: var(--dextinity-color-teal-500);
    --dextinity-brand-color-primary-600: var(--dextinity-color-teal-600);
    --dextinity-brand-color-primary-700: var(--dextinity-color-teal-700);
    --dextinity-brand-color-primary-800: var(--dextinity-color-teal-800);
    --dextinity-brand-color-primary-900: var(--dextinity-color-teal-900);
    --dextinity-brand-color-primary-950: var(--dextinity-color-teal-950);
}
```

If your styles use cascade layers, put the rules in a layer after the layer of the library:

```css
@layer dextinity, brand;

@layer brand {
    :root {
        /* … */
    }
}
```

There are color scales with the steps 50 to 950, a corner radius for each kind of element, and two fonts:

## Replace the font

The components take their font from a brand token, not from the font of the page. Load your font, and set the token to it. If your font loader gives you a CSS variable instead of a font name, set that variable on the `html` element.

```css
:root {
    --dextinity-brand-font-family-sans: "Source Sans 3", sans-serif;
}
```

## Customize a part of the application

To use another brand in one part of your application, wrap that part in another `Theme`, and give it a class that sets the brand tokens:

```css
.checkout {
    --dextinity-brand-color-primary-50: var(--dextinity-color-teal-50);
    --dextinity-brand-color-primary-100: var(--dextinity-color-teal-100);
    --dextinity-brand-color-primary-200: var(--dextinity-color-teal-200);
    --dextinity-brand-color-primary-300: var(--dextinity-color-teal-300);
    --dextinity-brand-color-primary-400: var(--dextinity-color-teal-400);
    --dextinity-brand-color-primary-500: var(--dextinity-color-teal-500);
    --dextinity-brand-color-primary-600: var(--dextinity-color-teal-600);
    --dextinity-brand-color-primary-700: var(--dextinity-color-teal-700);
    --dextinity-brand-color-primary-800: var(--dextinity-color-teal-800);
    --dextinity-brand-color-primary-900: var(--dextinity-color-teal-900);
    --dextinity-brand-color-primary-950: var(--dextinity-color-teal-950);
}
```

```tsx
<Theme className={styles.checkout}>{/* … */}</Theme>
```

In such a part, when you change the corner radius of surfaces, also set the radii of cards, drawers, and tables again:

```css
.checkout {
    --dextinity-brand-radius-surface: var(--dextinity-radius-sm);
    --dextinity-brand-radius-card: var(--dextinity-brand-radius-surface);
    --dextinity-brand-radius-drawer: var(--dextinity-brand-radius-surface);
    --dextinity-brand-radius-table: var(--dextinity-brand-radius-surface);
}
```
