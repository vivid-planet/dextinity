Allow customizing the editor of `createTipTapRichTextBlock` through the theme

The block uses the new `TipTapRichTextEditor` from `@dextinity/admin`, so `DextinityAdminTipTapRichTextEditor` and `DextinityAdminTipTapRichTextEditorToolbarButton` in the theme apply to it. The toolbar's class name changes from `DextinityAdminTipTapToolbar-root` to `DextinityAdminTipTapRichTextEditor-toolbar`.
