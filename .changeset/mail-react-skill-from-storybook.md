Include the usage guide of `@dextinity/mail-react` in the `dextinity-mail-react` skill

The skill is generated from the Storybook of `@dextinity/mail-react` for each release. It contains the docs pages and the components with their props and stories, the same content the Storybook's MCP server serves. Agents no longer need the MCP server to be connected.

Reinstall the agent features to get the new skill:

```sh
npx @dextinity/cli install-agent-features
```
