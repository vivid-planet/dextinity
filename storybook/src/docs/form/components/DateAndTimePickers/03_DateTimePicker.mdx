# Date-Time Picker

**`DateTimePicker` and `FinalFormDateTimePicker` from `@dextinity/admin-date-time` are deprecated. Use [`DateTimePicker`](?path=/docs/@dextinity/admin_components-datetime-datetimepicker--docs) or [`DateTimePickerField`](?path=/docs/@dextinity/admin_components-datetime-datetimepickerfield--docs) from `@dextinity/admin` instead.**

## Value type

The `value` prop and the value returned by `onChange` are of type `Date`.
