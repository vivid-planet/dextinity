# Time-Range Picker

**`TimeRangePicker` and `FinalFormTimeRangePicker` from `@dextinity/admin-date-time` are deprecated. Use [`TimeRangePicker`](?path=/docs/@dextinity/admin_components-datetime-timerangepicker--docs) or [`TimeRangePickerField`](?path=/docs/@dextinity/admin_components-datetime-timerangepickerfield--docs) from `@dextinity/admin` instead.**

## Value type

The `value` prop and the value returned by `onChange` are objects with `start` and `end` time-values. <br />
Each time-value is a 24-hour `string` formatted as `HH:MM`, similar to the [HTML time input](https://developer.mozilla.org/en-US/docs/Web/HTML/Element/input/time).

```ts
type TimeRange = {
    start: string; // "HH:MM"
    end: string; // "HH:MM"
};
```
