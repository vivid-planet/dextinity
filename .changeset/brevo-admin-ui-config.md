Rebuild the Brevo config page with `@dextinity/ui`

The config page is an edit page with a save state in the header and saves with Ctrl/Cmd+S. When the senders or double opt-in templates can't be loaded from Brevo, the page says so instead of failing. The notice for a missing config on the other Brevo pages is a `Banner`.
