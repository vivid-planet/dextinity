Make the header search usable with the keyboard

Use the arrow keys to move through the results, Enter to open the active result, Tab and Shift+Tab to switch the type tab, and Escape to clear the search, then close the dialog. Ctrl+K (⌘K on Mac) also closes the open dialog.
Screen readers announce the search input as a combobox with the active result and the number of results.
