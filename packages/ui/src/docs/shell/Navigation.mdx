# Navigation

The main navigation is the sidebar of an application. It links to the main areas of the application, so that users can go to each area from every page.

## When to use which component

- [`NavItem`](?path=/docs/shell-navitem--docs): one item for each area. Set `active` on the item of the current page. Use it only in the main navigation.
- [`MenuSectionHeader`](?path=/docs/shell-menusectionheader--docs): a name above a group of related items, for example "Content" and "System". If you want an action that applies to the whole section, give it to the header's `action`.
- Nested items: for the sub-areas of an area, with `level` set to their depth (`2` or `3`). Make their parent item `expandable` when the nested items make the navigation too long to scan.

## How to build it

- Put the navigation in a `nav` element with an `aria-label`, and set its width there.
- Put the items under a `MenuSectionHeader` in a list. Set an `id` on the header's label with `slotProps={{ label: { id } }}`, and give the list `aria-labelledby` with this `id`.
- Put nested items in a list inside the item they belong to.
- Render an `expandable` item as a `button` with `aria-expanded`, and render its nested list only while it is expanded.
