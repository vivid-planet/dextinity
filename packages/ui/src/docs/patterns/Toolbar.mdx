# Toolbar

The toolbar is the top of a page: an optional breadcrumb, and below it the title of the page with its actions.

## When to use which component

- [`Typography`](?path=/docs/foundations-typography--docs): the title of the page with `variant="displayL"`, and an optional support text below it with `variant="small"`.
- [`IconButton`](?path=/docs/building-blocks-iconbutton--docs): the back button, the info button next to the title, and "More actions" on small screens.
- [`Button`](?path=/docs/building-blocks-button--docs): the actions of the page. See [Actions](?path=/docs/patterns-actions--docs).

Until `@dextinity/ui` has components for the toolbar and the breadcrumb, build them with your own elements, as in the examples.
