Require `graphql-scalars` v2 as a peer dependency

Projects often depend on `graphql-scalars` themselves, for instance for the code generated by the API Generator. As a peer dependency, `cms-api` and `brevo-api` use the project's copy. Before, a project on a different major got a second copy, and the GraphQL schema couldn't be built because both copies define a scalar named `JSONObject`.

See the [migration guide](https://cms-docs.dextinity.com/docs/migration-guide/migration-from-v10-to-v11) for the required steps.
