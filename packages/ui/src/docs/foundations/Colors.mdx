# Colors

Semantic colors derived from the brand and the color scheme. Values and contrast ratios are computed live — switch the color scheme and the brand in the toolbar.

## Text

Four text colors: Default, Subtle, Disabled, and Accent. Status text colors are listed under [Status](#status). Contrast per WCAG 2.2: body text needs 4.5 : 1 (AA), large text and icons 3 : 1.
